# 卡片链接格式速查

卡跳跳涉及三种“链接”，不要混用。

## 1. 正文跳转引用（卡跳跳真正写入的）

```text
[Card#ID/<目标 root_id>#显示文字]
```

- `<目标 root_id>` 是目标卡的稳定 ID，不是 `card_id`；
- 单向和双向的**语法相同**，区别只在改哪张卡：
  - 单向 A → B：只修改 A，B 只读核实；
  - 双向 A ↔ B：A、B 各插入一条指向对方的引用；
- 修复或审计时，已有引用必须按 `root_id` 解析，不能按标题猜；
- 更新请求使用被修改卡所属牌组的实际 `card_id`，不能把 `root_id` 当更新 URL 的卡 ID。

示例（ID 仅示意）：

```text
[Card#ID/6aee011bbbfde62ce400bf95#复合铰链]
```

## 2. 网页卡片定位链接（不是 CardLink 产出）

```text
https://www.markji.com/deck/editor/<牌组网页 ID>?cardId=<卡片网页 ID>
```

这是墨墨网页端的编辑器深链，用于打开/定位某张卡，不是卡跳跳生成的跳转语法，也不能直接当 `[Card#...]` 写进正文。

- `<牌组网页 ID>`、`<卡片网页 ID>` 通常是 24 位网页 ID；
- 它们**不是**官方 API 的 `mkjd_...` 牌组 ID，也不是 Card 引用里的 `root_id`；
- 两套 ID 不能互相换算；
- 链接能打开，不代表其他账号有权限，也不等于已分享。

## 3. 导入/外部分享链接

牌组级链接可能形如：

```text
https://www.markji.com/deck/<牌组网页 ID>
```

这是牌组入口，不是单卡跳转，也不是 CardLink 的写入格式。不要把牌组链接当卡片链接。

## 默认视觉样式（可选，不属于链接语法）

`[Card#...]` 只负责跳转，不规定标题、颜色或编号。  
如果要套用“考点直击 / 题目 + 编号链接”的常见版式，可使用 MemoCardest 工具箱的绿色小标签风格：

```text
[T#B,!ffffff,!!36b59d# 考点直击 ]
[T#B,!36b59d,!!e6f3f0# 题目 ] [Card#ID/<root_id>#显示文字] [T#!36b59d,!!e6f3f0,up# 1 ] [Card#ID/<root_id>#显示文字] [T#!36b59d,!!e6f3f0,up# 2 ]
```

- 第一行是深绿底白字标题；
- 第二行是浅薄荷底墨绿字标签，后接链接和上标编号；
- 多个链接按 `1`、`2` 编号；
- 这是**内容模板**，不是 CardLink 自动注入的默认样式；
- 已有卡片应优先保留它自己的标题、颜色和编号习惯；不要为了套模板重写整张卡；
- 改主题时替换颜色值即可，链接语法不变。

## 常见错误

- 把 `card_id` 写进 `[Card#...]`：跳转会指向错误对象；正文必须用目标 `root_id`。
- 把 `root_id` 当成 API 更新 URL 的卡片 ID：更新会失败或改错。
- 以为单向/双向有不同语法：语法一样，方向由改哪张卡决定。
- 以为网页 `/deck/editor/...?cardId=...` 是卡跳跳产出：它只是网页定位链接。
- 只凭标题/正文相似就认领目标卡：必须先核对 `root_id`。

## 交付时怎么区分

```text
写入：Card 引用（root_id）
导航：网页深链（网页 deckId/cardId）
分享：牌组链接（deckId）
```

只读审计不写卡；网页链接不证明 API 写入成功；API 回读通过也不等于客户端点击已验收。
